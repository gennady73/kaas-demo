# Offline R3 planning evidence

These are preserved preparation receipts. Source-index fingerprints identify shared-workspace handoffs and version-specific primary references; those parent-workspace documents are provenance references, not standalone checkout dependencies. Preparation-validation records the original checked artifact hashes and the exclusion of concurrent native-package edits. The focused validator and published R2 files are sufficient for portable plan checks; the recorded working-tree auditor candidate is not certified here.

Publication changes prose and adds portable copies of these receipts; original preparation hashes remain historical. Publication-checks records subsequent checks. No cluster access or workloads are part of either step. This package authorizes no registration, deployment, fault, notification or test.
