# Frozen offline replay inputs

These are byte-preserving copies of the reviewed contract and prior C3/C6 **offline** review records. The `.txt` reviews are historical records; their original workspace-relative references may require the shared project workspace. They do not approve the newer native draft. No credential values are included.

Use these files with the explicit `replay_offline.py` arguments; all flags in the contract remain false. Source locations and SHA-256s are recorded in `provenance.json`.
